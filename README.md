# The Impossible Elevator: Jasmine Mak

Plain HTML/CSS/JS portfolio. No build step. Works on GitHub Pages.

## Folder structure
```
index.html
css/style.css
js/script.js
data/projects.js        <- edit ALL project text, images, hotspots here
assets/images/          <- your 9 WebP graphics (already included)
assets/projects/<slug>/ <- project images (rendered from your PDF pages)
assets/documents/resume.pdf   <- ADD your resume here
data/archive.js         <- ALL text + image map for floor 07, The Design Archive
js/archive.js           <- how the Archive behaves (viewer, zoom, compare)
assets/archive/         <- Archive images (sketchbook, technical, systems, collaborative)
assets/documents/archive/ <- optional full PDFs linked from the Archive
```

## Preview on your computer
1. Unzip the folder. 2. Double-click `index.html` (it opens in your browser). Everything works offline.

## Publish on GitHub Pages
1. Create a free account at github.com and click **New repository**. Name it e.g. `portfolio`, set Public, click **Create**.
2. Click **uploading an existing file**. Open the unzipped folder and drag in **everything inside it** (index.html must end up at the top level, with the css, js, data and assets folders beside it). Click **Commit changes**.
3. Go to **Settings → Pages**. Under *Branch* choose `main` and `/ (root)`, then **Save**.
4. After 1–2 minutes your site is at `https://YOUR-USERNAME.github.io/portfolio/`.

## Things to personalise
- **Email:** in `data/projects.js`, change `SITE.email` (currently a placeholder, I did not invent one).
- **Résumé:** save your PDF as `assets/documents/resume.pdf`.
- **Project images:** the images in `assets/projects/` are full pages rendered from your portfolio PDF. For individual drawings and renderings, add files to the same folders and edit each project's `gallery` list. Use the group `"Technical Drawings"` or `"Final Renderings"` to list them under those headings.
- **Hotspot positions / button alignment:** hotspots use `x, y, w, h` (% of the image) in `FLOORS`. Elevator button positions are the `--y1…--y6` and `--b-x` variables at the top of `css/style.css`.

## Door animation
Doors open using two clipped slices of your own `elevator-interior.webp` that slide apart over the gallery image, so nothing is stretched. For a more realistic result, you can later supply separate `door-left.webp` and `door-right.webp` cut-outs and use them as the `.door.l` / `.door.r` backgrounds in the CSS.

## Sound
Music and the elevator "ding" are generated by the browser (Web Audio), so there are no audio files to add. Sound starts after the visitor clicks ENTER, and the "♪ Sound" button in the menu turns it on/off. To change the volume, edit `musicBus.gain` (`setTargetAtTime(.1, …)`) and the `level` values for `ding` in `js/script.js`; lower numbers are quieter.

## Floor atmospheres
Each floor has a `theme` and `mood` in `FLOORS` (`data/projects.js`). The matching lighting, vignette, plaque materials and door-light colour live in the "Environmental storytelling" block at the end of `css/style.css`. Change the numbers there to make any floor brighter, darker or warmer. No new images are required.

## Floor 07: The Design Archive
A walkable architect's studio-gallery with four sections: **A** Sketchbook & Observation (rough vs final, side by side or switch), **B** Technical & Spatial Thinking (enlargeable sheets with zoom), **C** Systems & Design Research (ModuNest, linked to the main project), **D** Human-Centred & Collaborative (Living Without Barriers, D Building).
- Reach it from the elevator (button 07, or press 7), from the **Archive** menu link, or from **All Projects**.
- Move with the section bar, the side arrows, or the ← → keys. Esc closes the viewer. In the viewer: + / − / 0 zoom, double-click zooms, drag pans.
- **Edit content** in `data/archive.js`. The image map is in the comment at the top of that file. Replace any image by saving your file over the same filename (WebP, JPG or PNG; if you change the extension, edit the path in the file). Missing images show an "Image coming soon" card.
- **Background:** `assets/images/archive-studio.webp`.
- The elevator panel image now has seven buttons; adjust `--y1…--y7` at the top of `css/style.css` if one looks off.

## Homepage text
Edit the words in `index.html` inside `<div class="hero">`. Reveal timing and button hover are in the "Home" block of `css/style.css`.

## Updating GitHub later
Open your repository, click **Add file → Upload files**, drag in the *contents* of the unzipped folder (index.html, css, js, data, assets), choose to replace existing files, then **Commit changes**. Pages refreshes in 1–2 minutes (hard-refresh with Ctrl/Cmd+Shift+R).
